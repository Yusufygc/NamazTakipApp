# Ham kaynaklar (Raw Sources)

Bu klasör, projeye dışarıdan gelen ve değiştirilmemesi gereken kaynaklar içindir: PDF'ler, API dokümanları, makaleler, ham veri dışa aktarımları, ekran görüntüleri.

Kurallar:

- Buradaki dosyalar sabittir (immutable). Düzenlenmez, yalnızca okunur.
- Bir kaynağı bilgi tabanına almak için "Bunu Ingest et" denir; sentez `docs/wiki/` altında yapılır ve `docs/wiki/log.md` dosyasına işlenir.
- Dosya adına kaynağın tarihini ve kısa adını yazın (`2026-10-26-diyanet-vakit-tablosu.pdf`).

Şu an bu klasörde ham kaynak yoktur. Wiki sayfaları: [docs/wiki/index.md](../wiki/index.md).
